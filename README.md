# Alex AI – Fully Automated Voice Assistant (Java + XML)

Voice-controlled Android assistant powered by the Gemini API.

## Build on GitHub (no setup)
1. Create a new GitHub repo and upload all files in this folder.
2. Open the **Actions** tab → **Build APK** → download `Alex-AI-debug-apk` when it finishes.

## Build locally
Open the folder in Android Studio (JDK 17) and press Run, or run `gradle assembleDebug`.

## First run
1. Get a free key at https://aistudio.google.com/apikey → Settings tab → paste → Save.
2. Grant permissions, then allow "Display over other apps".
3. Enable **Alex AI** in Accessibility settings.
   On Android 13+ for sideloaded apps: App info → ⋮ → **Allow restricted settings** first.
4. Tap **Start Alex**, then say "Hey Alex" or tap the floating orb.
